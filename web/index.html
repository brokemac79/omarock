LOCAL FIRST INTERFACE

Make the connection.

This dashboard runs on your computer. Robot access may use Roborock’s cloud.

Sign in once

cd ~/.config/omarchy/plugins/io.github.brokemac79.omarock
~/.local/share/omarock/venv/bin/roborock login --email YOUR_EMAIL

Enter the email code in your terminal. Never put credentials into a repository.

Supervised controls

Live actuation is untested on Saros 20. After arranging a supervised test, enable allow_control in ~/.config/omarock/config.json and restart the backend. Never enable it just to clear an error.

Honest limitations

  • Browsing another floor does not switch the robot’s map.
  • Only the current floor map image is available.
  • Tank flags are not water percentages.
  • Historical room coverage can be unknown.
  • Zone calibration and cleaning controls need a supervised device test.
